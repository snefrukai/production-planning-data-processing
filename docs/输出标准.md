# 在制分析输出标准

## 目标

根据《派工进度追踪表》输出每个产品型号的在制情况，用于后续和库存、客户需求对比。

## 输入要求

上传表格必须包含以下列：

- 派工主题
- 产品型号
- 派工数量
- 加工工序
- 合格数量

以下列存在时会被使用：

- 订单主题
- 产品名称

## 分组规则

- 计算时先按 `产品型号` 分组。
- 同一 `产品型号` 在多个 `派工主题` 中出现时，合并为同一条产品记录。
- 输出展示时，相同工序序列的产品型号放在同一个数据区块，共享同一组动态工序表头。
- `派工主题` 是派工批次/序列信息，不等同于 `订单主题`。
- 同一派工主题对应多个产品型号时，系统继续按产品型号分别计算，并在日志和 Streamlit 页面提示用户复核源表。

## 输出列

固定列顺序必须为：

```text
产品型号 | 产品名称 | 在制汇总 | 派工说明 | 详细派工说明 | 派工主题 | [工序1] | [待工序1] | [工序2] | [待工序2] ...
```

说明：

- `产品型号`：来自源表 `产品型号` 列。
- `产品名称`：来自源表 `产品名称` 列；没有该列时可为空。
- `派工主题`：派工批次/序列信息，来自源表 `派工主题`，不从 `订单主题` 或 `订单编号` 兼容读取。
- 动态工序列按该产品型号的工序出现顺序输出。

## 计算口径

- `【自制】` 是批次标题，不是工序。
- `派工数量` 只对第一道工序有效。
- 第一道工序待处理量 = 产品型号总派工量 - 第一道工序合格数量。
- 后续工序待处理量 = 上一道工序合格数量 - 当前工序合格数量。
- 待处理量小于 0 时按 0 输出。
- `详细派工说明` 按每个派工主题自身的工序顺序计算，不套用其他派工主题的工序。
- `在制汇总` 等于 `详细派工说明` 中所有数量之和。

## 输出文件

- 页面展示处理结果。
- 同时提供 CSV 和 XLSX 下载。
- 本地批处理结果输出到 `script/output/`。
